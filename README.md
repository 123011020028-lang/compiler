# Natural Language to C Code Converter Using Compiler Phases

Developed a **Natural Language to C Code Converter** that transforms simple English programming instructions into executable C code using the concepts of **compiler design**. The project demonstrates how different compiler phases can be applied to process natural language input, identify its meaning, generate an intermediate representation, and produce structured C code.

### Key Features

* Natural language input processing
* Lexical analysis and tokenization
* Syntax and semantic analysis
* Intermediate code generation
* Code optimization
* C code generation
* Error detection and handling
* Compiler-phase-based architecture

### Technologies

**Python, Compiler Design, NLP, Regular Expressions, C Programming**

### Project Outcome

The project provides a practical demonstration of how compiler phases can be combined with natural language processing to automatically convert human-readable programming instructions into C source code.
